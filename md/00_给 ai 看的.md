## 页面排版与构建规则
1. **文章发布规则**：
   - 发布时间以第一次发布为主，后面的编辑暂且不算；草稿目录（`md/草稿/`）里的文章不发。
   - 每一次都可能修改以前的，所以如有更新请以最后编辑时间为主。

2. **字体与字重规范**：
   - 全局宋体采用自托管思源宋体（Noto Serif SC: 400 与 700）。
   - 代码等宽字体采用汉仪仿宋（ChineseMono）。
   - 大标题（`#logo`）、文章标题（`.article-title`）、章节标题（`h1, h2, h3, h4`）均采用 700（加粗）。
   - 换行还是回车自行判断，

3. **左侧大纲规范 (Cloud 风格)**：
   - 电脑端：在文章页左侧提供固定悬浮大纲（`#floating-toc`），跟随滚轮滚动自动高亮当前章节，激活点带中型曲线高亮，具备层级关系。
   - 移动端：左侧悬浮大纲自动隐藏，大纲自动收录在左上角抽屉侧边栏顶部（`.mobile-nav-toc`），点击目录项可平滑滚动并自动收起抽屉。

4. **log（随笔/动态）同步规则**：
   - 读取 `md/02_log.md`，按倒序（最新在最前）生成到 `thoughts.html` 的时间线流中。

5. **组件复用规范 (100% 零构建、0 依赖)**：
   - 移动端侧边抽屉（`#mobile-nav`）采用原生组件化复用，页面 HTML 中只需保留 `<nav id="mobile-nav"></nav>` 空容器，由 `js/script.js` 统一渲染标签树、标签词云，并在文章页自适应生成目录（顶栏主导航保持在顶部，绝不放入侧边栏重复显示）。
   - 顶栏主导航的 `.current` 高亮由 `js/script.js` 自动根据当前 URL 识别，无需在静态 HTML 中手动配置。

6. **深色模式与双语规范 (Dark Mode & Language Toggle)**：
   - 采用 `localStorage` (`heptazero_theme`) 结合系统媒体查询 `prefers-color-scheme`，并在全站页面 `<head>` 内嵌轻量防白屏闪烁脚本（渲染前预置 `dark-mode` 类名）。
   - PC 端顶栏右侧（`#sub-nav`）常驻展示 `[中 / EN]` 与 `[ ☀️ / 🌙 ]`，社交联系图标（GitHub、Email）默认收起隐藏，鼠标悬停时平滑划出展开，保证视觉极简。
   - 移动端在窄屏自动折叠顶栏 `#sub-nav`，统一将 `[中 / EN]`、`[ ☀️ / 🌙 ]`、GitHub 与 Email 整合固定在侧边抽屉底部工具栏（`.mobile-nav-toolbar`）。

7. **侧边抽屉雾化与标题吸顶规范**：
   - 侧边抽屉采用左侧滑出，右侧预留遮罩空间便于右手单指点击收起。
   - 抽屉滚动内容区（`.mobile-nav-scroll-body`）采用 CSS `mask-image` 渐隐雾化上下边界。
   - 抽屉内各模块标题（`h3.widget-title`）配置 `position: sticky; top: 0` 吸顶固定，长章节浏览时标题固定不随滚动消失。

8. **文章尾部规范**：
   - 文章末尾保持纯粹与留白，不添加冗余的格式化联系小注（不使用 `.article-signoff`），消除评论区前杂乱堆叠的细线分割，使正文与讨论区自然过渡。

9. **发布前全量巡检与校对规范**：
   - 每次收到发布指令时，务必先用 `git status` / `git diff` 扫描所有 `md/` 源文档，检查既有文章是否有微调并一并同步到 HTML。
   - 发布新文章前，先检查错别字、标点与语法，梳理出适合外挂 Wikipedia 链接的人名/词条，以及适合拆入右侧旁批（`.sidenote`）或悬浮卡片（`.hover-card-anchor`）的背景科普与典故，向博主汇报并给出建议、确认后再正式发布。
   - **Markdown 双向同步语法**：凡是新增或修改的右侧旁批（`.sidenote`），必须同步写回对应的 `.md` 源文档中（使用标准脚注 `[^1]` 与文末 `[^1]: ...`）；悬浮卡片（`.hover-card-anchor`）在 `.md` 中统一使用醒目的 `【词条｜解释内容】` 标记；Wikipedia 外链直接保留为标准 Markdown 链接，方便博主随时二次编辑。
