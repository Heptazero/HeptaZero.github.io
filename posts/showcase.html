$$\int_{-\infty}^{+\infty} e^{-a x^2} \, dx = \sqrt{\frac{\pi}{a}} \quad (a > 0)$$

2.3 现代深度学习注意力机制

在大语言模型与 Transformer 架构中，Scaled Dot-Product Attention（缩放点积注意力）定义如下：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

其中 $Q, K, V$ 分别代表 Query、Key 和 Value 投影矩阵，$\sqrt{d_k}$ 充当防止梯度饱和的温度缩放因子。

2.4 拓扑学同伦连续变形

若两映射 $f, g: X \to Y$ 是同伦的，则存在连续映射族 $H: X \times [0, 1] \to Y$ 满足：

$$H(x, 0) = f(x), \quad H(x, 1) = g(x), \quad \forall x \in X$$

4.1 PyTorch 多头注意力实现

import torch
import torch.nn as nn
import math

class ScaledDotProductAttention(nn.Module):
    """Scaled Dot-Product Attention in PyTorch"""
    def __init__(self, d_k: int):
        super().__init__()
        self.d_k = d_k

    def forward(self, q, k, v, mask=None):
        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        weights = torch.softmax(scores, dim=-1)
        return torch.matmul(weights, v), weights
