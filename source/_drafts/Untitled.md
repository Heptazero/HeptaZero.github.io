## 二、今日页（主页面）结构

### 时间轴与三区域

- **纵向时间轴**，左侧固定整点刻度（7、8、9…）。
- 页面高度可缩放（整体拉伸/压缩）；手机端双指竖直缩放。
- **时间轴竖线区域可左右拖动**，语义为切换视图：
  - **向左拖** → 露出**左侧：待办界面**（左：今日未安排待办竖排；右：已设置时间的待办，贴在时间轴线中间）。
  - **向右** → **右侧：时间记录界面**（当前时间块 + 已发生/进行中）。

### 三个逻辑区域

| 区域                          | 说明                                                         | 当前实现 |
| ----------------------------- | ------------------------------------------------------------ | -------- |
| **1. 待办堆（Todo Stack）**   | 仅「今天尚未安排到具体时间」的事项；与 Todo 页无关；被安排到今天时间后从堆中消失；可拖到放置区 | ✅ 有     |
| **2. 放置区**                 | 拖入后，待办方框在**中轴线左侧一点**                         | ✅ 有     |
| **3. 时间轴中线**             | 可拖动的分割线；左=待放置区，右=时间记录区；两侧共用同一时间刻度；中线右侧一点为时间数字刻度 | ✅ 有     |
| **4. 时间记录区（Timeline）** | 只显示已发生/正在进行的时间块；不放置「未发生的待办」        | ✅ 有     |

### 核心交互语义

- 待办只存在于：**待办堆** 或 **时间轴左侧（放置区）**。
- 拖到时间点并放下后，才生成**时间块**；未放入前不是时间块。
- 删除操作均有**撤回**。高度可配置，颜色后期可改。

## 三、顶部导航栏

- **右上角红色**：从「记录的起床时间」起算已流逝时间；过午睡/12 点（可配置）后改为显示**剩余时间**。
- **左侧**：当前「页面」名称（可设置里自定义，如 今日/Todo 等）。

---

## 四、底部导航栏（按页面）

- 底部三个按钮**随页面变化**。
- 在底部导航容器**上滑** → 搜索界面。

| 页面     | 按钮                      | 当前实现                             |
| -------- | ------------------------- | ------------------------------------ |
| **今日** | 专注 \| 今日 \| 日历      | ✅ 有（专注文案可自定义，如「起床」） |
| **Todo** | 今日 \| +（加号） \| 日历 | ✅ 有（+ 行为占位）                   |

日历：点击后顶部下拉日历；日期可做热力图等（标签/项目/得分）。

---

## 五、待办页（Todo）

- 多种视图可组合：**格子视图**、**流视图**、**列表视图**（今日/明天/周待办）。
- **格子视图**：可添加格子、长按交换、设颜色；+ 添加格子；长按待办可移动/跨格子；点击格子进入该格子详情（编辑名、右上三点：颜色/删除/模板，底部加号加待办）。
- **列表视图**：可加集合（可折叠）、周待办可横排或格子，支持拖动。

---

## 六、统计页

- 可保存模板并命名，直接选用。
- 变量 1：对象（标签 / 项目）。
- 变量 2：视图（热力图、n 边形、折线图、甘特图等）。
- 变量 3：时间范围。

---

## 七、项目页

- 列表/大纲与层级、子任务。
- **进度条模式**：预期时间与目标量；图上有「当前进度」与「平均发力进度」（与甘特图一致）。
- 项目 / 习惯；量可增可减（如「稍后看」目标为 0）；增量可显示在时间块右下角 @。

---

## 八、专注界面

- 标题、描述；可选 **#标签**、**@**（项目/待办/时间块）；标签可层级、归档；@ 可网状关联。
- 可添加图片。
- 可设置：必须填标题或描述才能完成。

---

## 九、模板

- 如：某标签绑定模板后，标题/描述带占位（如「一句话输出：」「看到哪了：」）以提醒填写。

## 十、与代码的对应关系（简要）

| 产品概念                           | 代码位置                                                     |
| ---------------------------------- | ------------------------------------------------------------ |
| 顶部导航 + 一级标签                | `App.tsx` header，`view` / `setView`（uiStore）              |
| 今日核心区（放置区+中线+时间记录） | `App.tsx` 中 `view === 'today'` 的主内容                     |

| 放置区 + 中线                      | `App.tsx` 内 `placementAreaRef`、`splitLineRef`、`splitPosition` |
| 时间块 / 时间轴                    | `timeStore`、`useTimeline`、`timelineService`                |
| 底部导航                           | `App.tsx` footer                                             |
| 日历                               | `CalendarPanel.tsx`                                          |
| 专注                               | `FocusOverlay.tsx`                                           |
| Todo 页内容                        | `view === 'todo'` 时 `renderTodoView()`，目前为简单列表      |
| 统计/项目                          | `view === 'stats' \| 'projects'` 占位                        |
